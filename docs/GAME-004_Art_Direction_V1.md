# GAME-004《星图生态舱》美术方向定稿 V1

**baseline_version：GAME004-BASELINE-V1**  
**适用范围：ALL-GF03**  
**状态：production direction frozen；单项资产仍需按包审核。**

## 1. 视觉目标

“孩子是生态设计搭档”：在同一个圆润、可靠、可成长的星图生态舱内，看懂规则、安排对象、让对应生境产生自然变化。画面必须先支持分类辨别，再提供世界连续性；不得把分类训练画成纯题卡，也不得让装饰覆盖目标或区域。

## 2. 定稿风格

- 形态：圆润、玩具化、半写实PBR、动画电影质感；拒绝尖锐工具、伤害、惊吓、复杂机械恐惧。
- 色彩：生态舱外壳为暖米白、鼠尾草绿、柔和青绿；规则相关颜色仅在规则需要时作为明确特征，不被背景抢占。
- 镜头：竖屏、正面微俯视；顶部规则/范例安全区，中部区域与中立缓冲台，底部短提示与安全退出。
- 可读性：单屏只有一个当前目标；区域边界、可点/可拖热区和目标状态必须清楚；文字不是唯一线索。
- 分层：舞台外壳、区域底座、区域成长状态、目标/干扰对象、规则/范例、缓冲台、反馈、UI，逻辑与视觉可独立替换。

## 3. 已有探索资产的结论

`assets/processed/v001` 中的舞台、水域、林地、向阳花圃、维护区和少量对象，**通过统一风格与舞台方向验证**；但不是完整正式资产库，不得进入approved或用作120回合完成凭据。

已确认问题：水域/林地/花圃图当前细节密度偏高；规则图标仍是拼图候选；对象不覆盖形状/颜色/大小/功能/新实例/L5照片；无完整状态组。正式生产应保留材质、构图和配色语言，不直接复用为所有语义对象。

## 4. 120回合资产组

每个机会按 `baseline/game004_asset_matrix.json` 至少有：目标、对比/干扰、区域、规则/范例、自然结果、中立缓冲、低感官变体、权利记录。

### A. 共用系统资产

- 生态舱舞台：空舱、已连通、低感官三状态；水域、向阳花圃、岩地、夜园、工具湾、种子档案、生活整理记录的跨日状态。
- UI：规则条、范例卡、缓冲台、提示、暂停、安全退出、无障碍点选辅助；无伪文字。
- 音画：每个自然结果有轻量区域专属SFX和静音/低感官替代。

### B. L1：相同/高差异/形状

必须覆盖红圆种子、蓝方晶体、黄星叶、绿三角石、白圆水滴、紫方工具；鱼/鸟、花/锤子、苹果/小车、杯子/鞋、种子/水滴、灯泡/石头；圆/方及位置交换状态。

### C. L2：单规则属性/功能

颜色（红/蓝/黄）、大小（大/中/小）、形状（圆/方）、功能（敲击、清洁、维修、餐具）四组；同类新外观和位置交换状态。

### D. L3：新实例/切换/两级类别

水果、餐具、交通、穿戴/用品、水生类的新画风/角度/材质实例；颜色→形状→大小→颜色规则切换卡；食物→水果/主食、用品→餐具/工具、动物→水生/飞行的两层区域状态。

### E. L4：干扰/推断/四区

颜色无关的形状、大小、功能对象；范例成对组；水生、飞行、陆地、植物四生态区及鱼、鸟、兔、花、海龟、蝴蝶；多规则综合复核状态。

### F. L5：授权照片和生活桥

苹果、杯子、锤子、鞋、家庭大小盒等授权照片；厨房、餐桌、工具台、浴室、超市、野餐背景照片；每项必须独立rights record。无权利审核照片只能以占位卡存在，不能active。

## 5. 状态与反馈

目标对象：idle、focus、drag/tap-selected、neutral-buffer、resolved-success、return-neutral。区域：empty、available、highlight、growth/result、low-sensory。错误反馈不能伤害生物或强红叉；成功反馈不能统一烟花。

## 6. 美术生产与审核门禁

1. 从矩阵中按GP和语义组生成任务，禁止凭感觉出无映射素材。
2. 每批先做方向板，必须能看到本批资产、状态、语义和适用GP。
3. AI生成只入candidate；透明、边缘、语义、风格、状态和权利审核后才进processed/approved。
4. 每个资产必须有`asset_id`、`baseline_version`、引用机会、版本、来源、rights_status、low_sensory_variant引用。
5. 视觉审核必须使用实机帧：目标不遮挡区域、规则/范例不截断、L1–L5差异可读、低感官确实降载。
