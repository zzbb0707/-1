## 分图判断

### L1 v002

- 两区清楚：水域、向阳花圃。
- 中央水生种子荚/幼苗比v001的空花盆更适合作为可拖对象。
- 顶部空规则位仍可缩小或在游戏内覆盖。
- 底部提示安全区存在。
- 通过，作为L1布局母版。

### L3 v002

- 三区清楚：水域、林地/苔藓、向阳花圃。
- 顶部水/植物/光与切换箭头能表达规则切换位。
- 中央待分类对象清楚，底部提示安全区存在。
- 植物细节偏密，正式低感官版需减少。
- 通过，作为L3布局母版。

### L4 v002

- 四个功能区域基本成立：水域、林地、花圃、维护/工具区。
- 上方两列范例位和规则图标存在。
- 中央工具已儿童化，但“铲形工具属于哪个生态区”的规则语义仍需在正式关卡配置中明确，不能只靠画面猜。
- 四区密度较高，不能把整张图直接作为可点击逻辑；必须分层并建立大热区。
- 条件通过，作为L4构图母版，不是正式交互资产。

## 下一步门禁

1. 从母版抽取统一外壳与四区布局规范。
2. 使用Image 2按资产组生成：空区域底图、区域成功状态、中央对象、规则图标、范例卡；禁止直接粗切整屏母版。
3. Godot中用独立Sprite/TextureRect和大触控热区组合，保持规则和画面解耦。
4. L1/L3/L4各实现一个代表配置，再进行同一运行器的纵切试玩。
5. 低感官版关闭水流动画、强阳光、粒子，并减少植物层。
