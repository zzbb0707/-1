# GF-03 / GAME-004 二十个固定游戏日包总表 V1

每包固定6次“规则/范例—分类动作—生态结果”机会；当天不升L，屏幕结果不冒充生活整理。

## L1

### GF03-L1-P01 找到完全一样的家
1. 红圆种子配同图红圆区，发芽。  
2. 蓝方晶体配同图蓝方区，灯亮。  
3. 黄星叶配同图黄星区，叶片展开。  
4. 绿三角石配同图绿三角区，岩地稳定。  
5. 白圆水滴配同图水滴区，水流出现。  
6. 紫方工具配同图工具区，工作台启动。

### GF03-L1-P02 两种高差异区域
1. 鱼→水区，鸟→天空区。  
2. 花→花园，锤子→工具台。  
3. 苹果→食物区，小车→交通区。  
4. 杯子→餐具区，鞋→穿戴区。  
5. 种子→土地区，水滴→水区。  
6. 灯泡→光区，石头→岩区；记录高差异稳定。

### GF03-L1-P03 同形状回到一起
1. 红圆→圆区，蓝方→方区。  
2. 黄方→方区，绿圆→圆区。  
3. 大圆→圆区，小方→方区。  
4. 花纹方→方区，透明圆→圆区。  
5. 圆工具标→圆区，方种子标→方区。  
6. 左右区域交换后圆/方各一次，记录位置依赖。

### GF03-L1-P04 基础配对复核
1. 完全相同图配对。  
2. 鱼/鸟高差异分类。  
3. 圆/方形状分类。  
4. 花/工具功能高差异分类。  
5. 区域左右交换后配对。  
6. 新外观同形状配对；生成L1复核摘要。

## L2

### GF03-L2-P01 按颜色点亮花园
1. 红花→红光区。  
2. 蓝叶→蓝光区。  
3. 红色不同形状→红区。  
4. 蓝色不同大小→蓝区。  
5. 加入黄色第三区，黄种子→黄区。  
6. 三色位置交换后分类，花园分区点亮。

### GF03-L2-P02 按大小安排空间
1. 大圆石→大区，小圆石→小区。  
2. 大方箱→大区，小方箱→小区。  
3. 颜色变化但按大小分类。  
4. 材质变化但按大小分类。  
5. 加入中等区，中号种子→中区。  
6. 大中小各一件，区域位置交换后完成。

### GF03-L2-P03 按功能放回工具
1. 锤子→敲击工具区，刷子→清洁区。  
2. 木槌→敲击区，抹布→清洁区。  
3. 扳手→维修区，勺子→餐具区。  
4. 螺丝刀→维修区，杯子→餐具区。  
5. 新外观刷子→清洁区。  
6. 四类中当前开放三类，连续分类三件，工作台恢复。

### GF03-L2-P04 单规则分类校准
1. 明确按颜色分红/蓝。  
2. 明确按大小分大/小。  
3. 明确按形状分圆/方。  
4. 明确按功能分工具/餐具。  
5. 每回合规则卡只显示当前规则，分类新实例。  
6. 系统重复当前规则后再分类，比较规则类型提示依赖。

## L3

### GF03-L3-P01 换个样子还是同类
1. 不同画风苹果→水果区。  
2. 不同角度杯子→餐具区。  
3. 木制小车→交通区。  
4. 透明雨伞→穿戴/用品区。  
5. 真实质感鱼图→水生区。  
6. 六种新实例中连续分类，记录概念而非单图记忆。

### GF03-L3-P02 规则换了看这里
1. 前两件按颜色，红圆→红区。  
2. 清晰换规则为形状，红圆→圆区。  
3. 蓝方按形状→方区。  
4. 清晰换规则为大小，大方→大区。  
5. 小圆按大小→小区。  
6. 再换回颜色，蓝圆→蓝区；记录切换后首项。

### GF03-L3-P03 先大类再小类
1. 苹果先→食物，再→水果。  
2. 面包先→食物，再→主食。  
3. 杯子先→用品，再→餐具。  
4. 锤子先→用品，再→工具。  
5. 鱼先→动物，再→水生。  
6. 鸟先→动物，再→飞行；生态层级展开。

### GF03-L3-P04 新实例分类复核
1. 新画风水果按功能类。  
2. 新角度工具按功能类。  
3. 颜色变化对象按形状。  
4. 形状变化对象按大小。  
5. 明确信号后从颜色切到功能。  
6. 完成一次大类→小类两步分类，记录迁移与切换。

## L4

### GF03-L4-P01 忽略无关颜色
1. 规则按形状，红圆→圆区。  
2. 蓝圆仍→圆区。  
3. 规则按大小，大红方→大区。  
4. 大蓝圆仍→大区。  
5. 规则按功能，彩色锤→工具区。  
6. 同色食物与工具同时出现，按功能分别归区。

### GF03-L4-P02 从范例发现规则
1. 范例红圆/红方在一区，推断按颜色，红三角→该区。  
2. 范例蓝圆/蓝方在二区，蓝星→该区。  
3. 新盘范例大圆/大方同区，大三角→大区。  
4. 范例锤/扳手同区，螺丝刀→工具区。  
5. 范例鱼/鲸同区，海龟→水生区。  
6. 两个范例组同时呈现，分类新对象并说明只记录选择不要求口语解释。

### GF03-L4-P03 四个生态区域
1. 水生/飞行/陆地/植物四区，鱼→水生。  
2. 鸟→飞行。  
3. 兔→陆地。  
4. 花→植物。  
5. 新实例海龟→水生，记录近边界实例提示。  
6. 蝴蝶按当前明确规则→飞行区；四区生态同时启动。

### GF03-L4-P04 综合规则事件
1. 从范例推断按颜色并分类。  
2. 清晰换成按功能并分类。  
3. 无关颜色干扰下按形状。  
4. 四区中按生境分类新实例。  
5. 完成大类→小类两步。  
6. 规则卡、范例和区域位置变化后完成复核，生成规则专属摘要。

## L5

### GF03-L5-P01 真实照片分类
1. 授权苹果照片→水果。  
2. 授权杯子照片→餐具。  
3. 不同背景锤子照片→工具。  
4. 不同角度鞋照片→穿戴。  
5. 家庭真实大/小盒照片按大小。  
6. 三张真实场景物品照片按当前功能规则分类；仍只算屏幕照片证据。

### GF03-L5-P02 家庭物品整理桥
1. 屏幕杯子→餐具区，候选MP整理真实杯子。  
2. 屏幕积木→玩具区，候选MP收积木。  
3. 屏幕袜子→衣物区，候选MP分衣物。  
4. 屏幕勺子→餐具区，候选MP摆餐具。  
5. 屏幕书→阅读区，候选MP收书。  
6. 系统按家庭材料只发一项LIFE或OBS，不自动记生活完成。

### GF03-L5-P03 换场景保持概念
1. 厨房照片中杯子→餐具。  
2. 餐桌照片中杯子仍→餐具。  
3. 工具台照片中刷子→清洁工具。  
4. 浴室照片中刷子按当前明确规则→清洁工具。  
5. 超市照片中苹果→水果。  
6. 野餐照片中苹果仍→水果，记录跨背景稳定。

### GF03-L5-P04 生态舱到生活复核
1. 完全相同配对。  
2. 单属性颜色分类。  
3. 功能分类。  
4. 新实例概念分类。  
5. 清晰规则切换。  
6. 真实照片分类后只生成一个家庭整理包或OBS；屏幕与生活报告分开。

## 验收

20包均为具体规则和对象，不允许素材库随机改变类别语义；每包固定6回合；L4推断规则不要求口语解释；错误使用中性缓冲台；L5权利未核验不得active。
